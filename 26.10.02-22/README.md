## [22. Generate Parentheses](https://leetcode.com/problems/generate-parentheses/description/?envType=daily-question&envId=2026-10-02)

**난이도:** 🟡 Medium

### 문제 설명
Given n pairs of parentheses, write a function to generate all combinations of well-formed parentheses.

Example 1:
- Input: n = 3
- Output: ["((()))","(()())","(())()","()(())","()()()"]

Example 2:
- Input: n = 1
- Output: ["()"]

Constraints:
- 1 <= n <= 8
